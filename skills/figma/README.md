# Figma

> 整合 Figma API 進行設計自動化與程式碼生成

## 用途

提供與 Figma API 協作的全面指引，包括擷取設計資料、從 Figma 節點生成 React 元件與 Tailwind CSS、擷取設計 tokens（顏色、字型）、以及自動化設計轉程式碼的工作流程。同時涵蓋 Figma 外掛開發與 webhook 整合。

## 使用時機

- 從 Figma 檔案擷取設計 tokens
- 從 Figma 元件生成 React 或 CSS 程式碼
- 在 Figma 與程式碼之間同步設計系統
- 開發 Figma 外掛
- 自動化設計轉程式碼工作流程
- 使用 Figma Variables API 或 Dev Mode

## 主要功能

- 完整的 Figma REST API 參考（檔案、元件、圖片、樣式）
- Figma 節點轉 React 元件程式碼生成
- Figma 節點轉 Tailwind CSS class 生成
- 設計 token 擷取（顏色、字型），輸出 CSS 變數與 Tailwind 設定
- Variables API（Design Tokens 2.0）整合
- Figma 外掛開發腳手架（manifest、code、UI）
- Webhook 設定與處理
- 完整的設計轉程式碼流程範例

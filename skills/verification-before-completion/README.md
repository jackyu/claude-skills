# Verification Before Completion

> 在宣稱工作完成之前，要求執行驗證指令並確認輸出；永遠是證據先於斷言

## Purpose

強制在宣稱任何工作完成、已修復或已通過之前，先執行實際的驗證指令並確認輸出。未經驗證就宣稱工作完成是不誠實的行為，此技能確保每個成功宣稱都有對應的新鮮證據支持。

## When to Use

- 即將宣稱工作已完成、已修復或已通過
- 在提交（commit）或建立 PR 之前
- 進入下一個任務之前
- 委派工作給 agents 之後驗證結果

## Key Features

- 五步閘門函數：識別、執行、閱讀、驗證、宣稱
- 常見失敗模式對照表（測試、lint、建置、bug 修復、回歸測試、agent 委派、需求）
- 紅旗警示清單：捕捉「應該」「大概」「似乎」等不確定用語
- 合理化藉口防範表
- TDD Red-Green 驗證模式

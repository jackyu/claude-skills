# Remotion Best Practices

> Remotion 最佳實踐 — 使用 React 製作影片

## 用途

提供 Remotion 開發的領域知識，涵蓋動畫、音訊、影片、3D 內容、字幕、圖表、字型、文字動畫、轉場效果等。每個主題以獨立的 rule 檔案組織，包含詳細說明與程式碼範例。

## 使用時機

- 撰寫或審查 Remotion 程式碼
- 使用 React 建立影片合成
- 在 Remotion 中實作動畫、音訊、字幕或轉場效果
- 使用 Remotion 特有的 API（sequences、interpolation、compositions）

## 主要功能

- 30+ 個 rule 檔案，涵蓋所有主要 Remotion 主題
- 使用 Three.js 和 React Three Fiber 的 3D 內容
- 音訊與影片嵌入、裁剪、音量、速度、音高調整
- 字幕顯示（TikTok 風格）與 SRT 匯入
- 圖表與資料視覺化模式
- 字型載入（Google Fonts 與本地字型）
- 文字動畫與字型排版模式
- 序列、時序、轉場與裁剪模式
- TailwindCSS 整合
- 使用 Zod schemas 的參數化影片

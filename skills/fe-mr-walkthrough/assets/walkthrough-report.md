## 段落取捨原則

| 段落 | 出現條件 |
|---|---|
| 📌 一句話總結 | 必出 |
| 🗣️ 白話版描述 | 必出 |
| 🗺️ 變更地圖 | 必出 |
| 🔍 重點區塊白話解釋 | 必出（至少 1 個 hotspot） |
| 📊 流程圖 | 僅在涉及資料流／狀態流轉／請求流程時 |
| ✨ 好做法雷達 | 僅在掃描出 ≥ 1 個值得標記項目時 |
| ❓ 預備 FAQ | 必出 |
| 🚪 進入問答模式 | 必出 |
| 🔴 待詢問作者清單 | 互動結束時補上（若清單為空可省略） |
| 📒 後續行動 | 必出 |

## 排版風格

- Heading 階層：h1 標題、h2 主段、h3 hotspot 編號
- 中英文間空格、中文與數字間空格、全形標點（依共用寫作原則）
- 程式碼區塊用三個反引號 + 語言標記
- 避免超長表格，欄位數 ≤ 4

# Web Design Guidelines

> 依據 Web Interface Guidelines 審查 UI 程式碼的合規性

## 用途

根據 Vercel Labs 維護的最新 Web Interface Guidelines 審查 UI 程式碼檔案。每次審查前會從來源儲存庫取得最新指南，並以精簡的 `file:line` 格式輸出檢查結果，涵蓋無障礙性、UX 最佳實踐及設計合規性。

## 使用時機

- 使用者要求審查 UI 程式碼或檢查無障礙性
- 使用者想進行設計稽核或 UX 審查
- 使用者要求對照 Web Interface 最佳實踐檢查網站

## 主要功能

- 每次審查前從 Vercel Labs 來源儲存庫取得最新指南
- 依據 Web Interface Guidelines 的所有規則檢查檔案
- 以精簡的 `file:line` 格式輸出檢查結果
- 支援以檔案或模式參數進行針對性審查
